# プロ野球ペナントシミュレーター (Baseball Pennant Simulator)

2リーグ制（全12球団）・全143試合のペナントレースからクライマックスシリーズ、日本シリーズ、オフシーズン（タイトル表彰・殿堂入り・引退・ドラフト会議・新外国人スカウト・加齢成長）までを体験できる、本格野球経営・ペナントWebシミュレーションゲームです。

---

## 🌟 特徴

1. **リアルなリーグ戦・ポストシーズン構造**
   - セ・パ2リーグ（各6球団・全12球団）、全143試合（全試合DH制、延長12回引き分けあり）。
   - 毎シーズンの対戦日程はランダムに組み替えられ（球団順シャッフル）、同一カードが連続する6連戦は構造的に発生しません。
   - クライマックスシリーズ（ファースト／ファイナル・1位アドバンテージ）と日本シリーズ（7戦4勝制）。
   - CSの結果はセ・リーグ／パ・リーグの2列で表示。

2. **打席単位の精密な確率エンジン & リアルな継投・起用**
   - 打者（ミート・パワー・走力・幸運）vs 投手（球速・変化球・制球・スタミナ・幸運）による1打席ごとの打球判定。
   - **調子システム**: 毎試合各選手にランダムな調子補正（投手は制球が -20〜+10、野手はミートが -20〜+10）が適用され、試合結果にリアルタイムに影響。
   - **代打起用**: 6回以降、得点圏に走者がいる場面でミート値の高い控え野手を代打起用（同ポジションを守れる控えがいる場合のみ起用し、次イニング守備から交代）。
   - **勝ちパ・中継ぎの本格継投ロジック**:
     - 7回以降登板は原則1イニング交代、6回以前・延長戦登板は最長2イニング。
     - 僅差リード（1〜3点差）は8回セットアッパー／9回抑えを投入。
     - 4〜6点差リードは中継ぎの2番手・3番手、4点差以上ビハインドは敗戦処理（中継ぎ下位）を起用。
     - 先発が無失点継続中かつスタミナ十分なら8回・9回も続投（完封狙い）。
     - **2連投休養制限**: 勝ちパ・中継ぎ投手は2試合連続で登板したら、次の1試合は登板不可（ベンチ休養）。
   - 走塁・失策・死球・犠飛・併殺・盗塁の個別判定とイベントログ、スコアボード表示。
   - リーグ成績がリアルに収まるようバランス調整済み（本塁打王は概ね40本前後、首位打者は.310〜.320前後、盗塁王は40前後）。

3. **深みのある選手育成とロースター管理**
   - **投手の主要能力値（球威）と球速の再定義**: 投手は「球威（stuff）・制球・変化・スタミナ」を主要4能力値（1〜99）とし、球速は計算式（`球速 = 球威 ÷ 2.5 + 124`）から算出される表示パラメータとして一元管理。ドラフト初期値や才能値制約、週間成長（週次係数0.5）はすべて球威に適用され、リアルかつ破綻のない能力推移を実現。
   - 保有選手最大50名（一軍29名：投手14／野手15、二軍最大21名、故障者リストIL）。
   - 成長タイプ（早熟・普通・晩成・持続）と加齢による週間・年度末の能力変動。
   - **若手期（18〜22歳）の成長加速**: ピーク前（18〜22歳）の成長係数を `1.0` とし、入団後の有望株が着実に一軍主力へ育つスピードを確保（球威は上がりにくい能力値として週次係数 `0.5` を適用、球速は計算式により自動算出）。
   - 才能（Talent）・努力（Effort）・健康（Health）・幸運（Luck）のメンタル／体質パラメータ。
   - **成長の到達点は才能値と努力値で決まる**: 主要4能力の平均が「才能＋努力ボーナス」に近づくほど成長が鈍化。努力99で才能+10〜15、努力50で才能付近、努力50未満だと才能値には届きません。
   - 試合中の負傷離脱（最短11試合〜最長90試合、重傷ほど発生しにくい）と、一軍・二軍間の自動補充。
   - **選手詳細モーダル**: 当年成績、過去の年度別成績、通算成績、ポストシーズン成績、獲得タイトル、開幕からの能力成長値を網羅表示。

4. **直感的なオーダー・編成システム**
   - **野手オーダー**:
     - **スタメン同士の打順入れ替え**: ドラッグ＆ドロップまたはタップ選択（1人目をタップして黄色選択 ➔ 2人目をタップ）により、守備位置制限なく何番同士でも自由自在に打順を交換可能。
     - **スタメンと控え／二軍の入れ替え**: 同一守備位置（DH枠はポジション問わず全野手可）の適性制約を適用。
   - **投手編成**:
     - 先発1〜6・勝ちパ（セットアッパー／抑え）・中継ぎ1〜6・二軍（FARM）の枠間で、ドラッグ＆ドロップまたはタップ選択により、任意の投手同士を完全フリーに入れ替え可能。
   - **重複防止・自動修復ロジック**:
     - 全スロット（スタメン・控え・二軍）を横断した排他的整合性保証（`cleanTeamOrder`）により、同一選手が2箇所に現れる不具合を防止。
     - 過去のデータ不整合がある場合でも、「自動編成」ボタンを押すことでチーム全員のロースターが重複ゼロ・欠落ゼロの健全なベスト布陣へ一発で完全修復。

5. **充実のオフシーズン & ドラフト会議**
   - 個人タイトル表彰（首位打者・本塁打王・打点王・最優秀防御率・最多勝・MVP・沢村賞・新人王など）。
   - 主力能力がピークから20%以上低下した選手は引退。名球会基準を満たした選手の殿堂入り、現役・OB問わず年度別成績アーカイブ。
   - オフシーズン中の自由契約（戦力外通告。確認はアプリ内モーダル。自由契約後は二軍から自動補充して一軍人数を維持）。
   - 対話型ドラフト会議:
      - **適正な新人プール（初期値＆才能分布の最適化）**: 高卒（18歳）基準値は31〜49（平均40）、大卒・社会人は39〜58。低すぎず高すぎない適正バランス。才能値は下限45を保証しつつ高い才能ほど出にくいべき乗分布（45〜98）を採用し、希少なスター原石を発掘する楽しさを実現。投手の能力値も球威・制球・変化・スタミナの4能力平均として算出され、球速は球威から自動計算されるリアルなレンジに調整。
     - **1巡目は同時入札・抽選制**: 他11球団が同時に1巡目を決定（同一選手の指名は最大2球団重複調整）。単独指名は即決定、重複時は封筒をタップしてめくる抽選演出。外れた球団のみで外れ1巡目を同時決定・指名し、全球団1人が確定するまで外れ指名を反復。
     - **2巡目以降はウェーバー制（NPB準拠・スネーク方式）**: 各リーグを最下位から並べ、同順位は優先リーグ先でセ・パ交互。優先権はセ・パ隔年交互。2巡目はこの順、3巡目は逆順、以降折り返して戦力均衡を促進。
     - 候補リストは総合力・年齢・各能力（健康を除く）で並び替え可能。
      - スカウト報告（1ドラフトにつき最大10回、候補の隠しパラメータを調査開示）。
     - 自チーム戦力の参照モーダル、指名済み候補のグレーアウト、最大6名枠・任意「指名終了」。
   - 新外国人スカウト: ポジションを指定して候補を表形式で比較し獲得。才能値は日本人同様に下限45＆高才能ほど希少な分布が適用。適応値による独自成長（35歳以降は加齢で衰え）。

6. **洗練されたモダンUI & クラウド永続化**
   - ダーク／ライトテーマ切り替え。確認ダイアログはすべてアプリ内モーダル。
   - **通算記録マイルストーン達成通知**: レギュラーシーズン進行時に、マイチームの所属選手が投手の勝利（100勝/150勝/200勝/以降50勝ごと）・セーブ（100S/150S/200S/以降50Sごと）、野手の本塁打（200HR/300HR/以降100HRごと）・安打（1000安打/1500安打/以降500安打ごと）の偉業を達成した際、画面上部のお知らせバナーで通知（他球団の選手や春季キャンプ覚醒・交流戦開始などの不要な通知は行わず、自チーム選手の偉業達成のみをスマートに通知）。
   - 高速シミュレーション（1日 / 1カード3連戦 / 1週間 単位）。
   - **大容量クラウド保存（gzip圧縮 & 800KB分割保存）**:
     - 長期ペナントの成績データ蓄積による容量増大に対応し、ブラウザ標準 `CompressionStream` による gzip 圧縮および 800KB チャンク分割書き込み（Firestore の 1MB ドキュメント上限を安全に回避）を実装。
     - Google アカウントでのクラウド自動同期および「現在のデータを保存」ボタンによる即時セーブ。

## 🛠 技術スタック

- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Vanilla CSS（CSS変数によるデザイントークン、レスポンシブ、アニメーション）
- **設計**: ドメイン駆動設計（`domain/` にビジネスロジック、`match/` に試合シミュレーションを純粋関数として分離、`components/` にUI）
- **ストレージ**: LocalStorage（ローカル保存） & Firebase Cloud Firestore（クラウド保存・gzip圧縮・チャンク分割保存）
- **認証**: Firebase Authentication (Google ログイン)

## 🚀 クイックスタート

### 前提条件
- Node.js 18.0.0 以上
- npm

### インストール & 起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (Vite)
npm run dev

# プロダクションビルド（TypeScript型チェック含む）
npm run build

# ビルド成果物のプレビュー
npm run preview
```
