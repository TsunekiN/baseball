# プロ野球ペナントシミュレーター (Baseball Pennant Simulator)

2リーグ制（全12球団）・全143試合のペナントレースからクライマックスシリーズ、日本シリーズ、オフシーズン（タイトル表彰・殿堂入り・引退・ドラフト会議・新外国人スカウト・加齢成長）までを体験できる、本格野球経営・ペナントWebシミュレーションゲームです。

---

## 🌟 特徴

1. **リアルなリーグ戦・ポストシーズン構造**
   - セ・パ2リーグ（各6球団・全12球団）、全143試合（全試合DH制、延長12回引き分けあり）。
   - 毎シーズンの対戦日程はランダムに組み替えられ（球団順シャッフル）、同一カードが連続する6連戦は構造的に発生しません。
   - クライマックスシリーズ（ファースト／ファイナル・1位アドバンテージ）と日本シリーズ（7戦4勝制）。
   - CSの結果はセ・リーグ／パ・リーグの2列で表示。

2. **打席単位の精密な確率エンジン**
   - 打者（ミート・パワー・走力・幸運）vs 投手（球速・変化球・制球・スタミナ・幸運）による1打席ごとの打球判定。
   - 投球数・イニングに応じたスタミナ減少と継投（先発 → 中継ぎ → セットアップ・抑え）。
   - 走塁・失策・死球・犠飛・併殺・盗塁の個別判定とイベントログ、スコアボード表示。
   - リーグ成績がリアルに収まるようバランス調整済み（本塁打王は概ね40本前後、首位打者は.310〜.320前後、たまに大きく超える天才が出現。盗塁王は40前後）。

3. **深みのある選手育成とロースター管理**
   - 保有選手最大50名（一軍29名：投手14／野手15、二軍最大21名、故障者リストIL）。
   - 成長タイプ（早熟・普通・晩成・持続）と加齢による週間・年度末の能力変動。
   - 才能（Talent）・努力（Effort）・健康（Health）・幸運（Luck）のメンタル／体質パラメータ。
   - **成長の到達点は才能値と努力値で決まる**: 主要4能力の平均が「才能＋努力ボーナス」に近づくほど成長が鈍化。努力99で才能+10〜15、努力50で才能付近、努力50未満だと才能値には届きません。
   - 試合中の負傷離脱（最短11試合〜最長90試合、重傷ほど発生しにくい）と、一軍・二軍間の自動補充。選手詳細では今年度の能力成長値も表示。

4. **充実のオフシーズン & ドラフト会議**
   - 個人タイトル表彰（首位打者・本塁打王・打点王・最優秀防御率・最多勝・MVP・沢村賞・新人王など）。
   - 名球会基準を満たした選手の殿堂入り、現役・OB問わず年度別成績アーカイブ。
   - オフシーズン中の自由契約（戦力外通告。確認はアプリ内モーダル。自由契約後は二軍から自動補充して一軍人数を維持）。
   - 対話型ドラフト会議:
     - 1巡目は入札制（最大3チーム競合）。封筒をタップしてめくる抽選演出、外れ1巡目再指名。
     - **2巡目以降はウェーバー制（NPB準拠・スネーク方式）**: 各リーグを最下位から並べ、同順位は優先リーグ先でセ・パ交互（例: セ6位→パ6位→セ5位→パ5位→…→セ1位→パ1位）。優先権はセ・パ隔年交互。2巡目はこの順、3巡目は逆順、以降折り返して戦力均衡を促進。
     - スカウト報告（1ドラフトにつき最大5回、候補の隠しパラメータを調査開示）。
     - 自チーム戦力の参照モーダル、指名済み候補のグレーアウト、最大6名枠・任意「指名終了」。
   - 新外国人スカウト: ポジションを指定して候補を表形式で比較し獲得。適応値による独自成長（35歳以降は加齢で衰え）。

5. **洗練されたモダンUI**
   - 野手・投手のグラウンド配置ビジュアル、ドラッグ＆ドロップ編成と「ベストオーダー自動編成」。
   - 高速シミュレーション（1日 / 1カード3連戦 / 1週間 単位）と、最下部メニュー直上に固定された「次の試合に進む」ボタン。
   - チーム総合力の直下に表示されるお知らせ・ケガ通知バナー。
   - ダーク／ライトテーマ切り替え。確認ダイアログはすべてアプリ内モーダル（ブラウザ標準の confirm/alert は不使用）。

## 🛠 技術スタック

- **フロントエンド**: React 18, TypeScript, Vite
- **スタイリング**: Vanilla CSS（CSS変数によるデザイントークン、レスポンシブ、アニメーション）
- **設計**: ドメイン駆動（`domain/` にビジネスロジック、`match/` に試合シミュレーションを純粋関数として分離、`components/` にUI）
- **ストレージ**: LocalStorage による自動セーブ・ロード

## 🚀 クイックスタート

### 前提条件
- Node.js 18.0.0 以上
- npm

### インストール & 起動

```bash
# 依存パッケージのインストール
npm install

# 開発サーバーの起動 (Vite)
npm run dev

# プロダクションビルド（TypeScript型チェック含む）
npm run build

# ビルド成果物のプレビュー
npm run preview
```

ブラウザで `http://localhost:5173`（またはターミナルに表示されるURL）にアクセスしてください。
